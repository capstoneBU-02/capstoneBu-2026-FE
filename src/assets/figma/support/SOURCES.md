# 설정·도움말 아이콘 출처

2026-11-04에 사용자가 제공한 [Earmark Figma 파일](https://www.figma.com/design/87W9ZPWGTWqNHX7HTfQ1kZ)의 공식 디자인 컨텍스트에서 내려받았다. SVG 원본은 수정하지 않고 각 슬롯의 원래 크기로 사용한다.

| 파일          | Figma 노드 | 표시 위치                         | 원본 크기 |
| ------------- | ---------- | --------------------------------- | --------- |
| `help-16.svg` | `86:3338`  | 도움말 메뉴 · 자주 묻는 질문      | 16 × 16px |
| `file-16.svg` | `86:3344`  | 도움말 메뉴 · 이용 안내 다시 보기 | 16 × 16px |
| `info-16.svg` | `86:3349`  | 도움말 메뉴 · 문의하기            | 16 × 16px |
| `file-20.svg` | `86:2910`  | 작업을 찾을 수 없음               | 20 × 20px |

기존 사이드바 아이콘, 로고, 자체 호스팅 폰트와 이용 안내의 18px 아이콘 네 개는 기존 자산을 재사용한다. 임시 Figma asset URL은 런타임 요청에 사용하지 않는다.
