# 진입·온보딩 아이콘 출처

2026-11-04에 사용자가 제공한 [Earmark Figma 디자인](https://www.figma.com/design/87W9ZPWGTWqNHX7HTfQ1kZ?node-id=75-1215)의 공식 디자인 컨텍스트에서 내려받았다. 원본 SVG 파일을 수정하지 않고 그대로 사용한다. `OnboardingPage`의 이용 안내 네 행에서 각 아이콘의 원래 크기인 18 × 18px로 표시한다.

| 파일         | Figma 노드 | 이용 안내 항목  |
| ------------ | ---------- | --------------- |
| `file.svg`   | `75:1233`  | 남는 자료       |
| `lock.svg`   | `75:1241`  | 볼 수 있는 사람 |
| `shield.svg` | `75:1249`  | 받지 않는 정보  |
| `key.svg`    | `75:1257`  | 다시 들어올 때  |

로고는 동일한 Figma `brand/logo`를 구현한 기존 `BrandLogo`를 재사용한다. 폰트는 프로젝트의 자체 호스팅 Noto Sans KR, Geist, JetBrains Mono를 재사용한다. 임시 Figma asset URL을 런타임에서 요청하지 않는다.
