## 테스트·폰트·CI 경계

- [브라우저 테스트](../tests/browser/workspace.spec.ts)는 [별도 harness](../tests/browser/harness.tsx)에서 실제 화면과 훅을 실행한다. 테스트 제어기는 운영 `src`의 import 경로에 포함되지 않으며 Vite의 기본 배포 진입점은 `index.html`이다.
- `npm run test:browser`는 프로젝트에 고정한 Playwright를 실행한다. CI는 설치한 bundled Chromium을 사용한다. 로컬 `PLAYWRIGHT_CHANNEL` 지정은 선택 사항이며 특정 PC의 브라우저 경로나 도구 캐시를 요구하지 않는다.
- CI가 사용하는 [Playwright 설정](../playwright.config.ts)의 test discovery에서 실제 8개 테스트가 확인됐다. 테스트 0개를 성공으로 허용하는 옵션은 사용하지 않는다. 병렬 테스트는 각각 독립 페이지·브라우저 context를 사용한다.
- [테스트 TypeScript 설정](../tsconfig.test.json)을 solution references에 연결했다. 테스트와 Playwright 설정도 기존 앱의 strict 옵션을 상속하여 정식 `typecheck`에 포함된다.
- 폰트 파일 92개, 총 2,034,444바이트의 크기·SHA-256이 [출처 목록](../src/assets/fonts/sources.json)과 일치한다. CSS의 92개 URL과 파일이 대응하고, Noto Sans KR의 Unicode 범위가 현대 한글 완성형 11,172자를 포함한다. `font-display: swap`, 부분집합별 `unicode-range`, 기존 명시적 줄 높이를 유지한다.
- 폰트 출처와 Figma 메타데이터 확인 범위는 [폰트 출처](../src/assets/fonts/SOURCES.md)에 기록한다. 로컬 폰트는 공식 Google Fonts 배포본이며 Figma에 설치된 바이너리와 바이트 단위로 동일하다는 주장은 하지 않는다. 원문 OFL 3개와 배포 고지가 포함된다.

## 기존 개발 의존성의 잔여 위험

foundation 담당의 `npm audit --omit=dev` 결과는 0건이다. 전체 audit에는 기존 Vite 8.3.0과 fast-uri 3.1.8의 개발 의존성 취약점이 남아 있으며, 이번 Playwright 추가가 만든 새 취약점은 확인되지 않았다. Vite 개발 서버·에디터 실행 경로와 URL 처리 관련 위험이 남아 있으므로 이를 프로젝트 전체의 무위험 판정으로 해석하지 않는다.

해당 도구는 정적 배포물의 런타임에 포함되지 않는다. 이번 PR에서 개발 도구 버전까지 변경하지 않고 [개발 도구 패치 이슈 #5](https://github.com/capstoneBU-02/capstoneBu-2026-FE/issues/5)에서 추적하는 것으로 결정했다. 이 기준선의 후속 조치는 PR #4의 화면·동의 결함 수정 및 회귀 검증 판정과 구분한다.

최종 커밋을 push한 뒤 해당 HEAD의 CI 성공과 충돌 여부는 병합 담당이 다시 확인한다. 이전 커밋의 CI 성공을 이 수정본의 성공으로 간주하지 않으며, CodeRabbit의 자동 리뷰 생략 안내도 승인에 포함하지 않는다. 실제 API·인증·악보·오디오 처리나 모든 브라우저/보조기기의 검증은 이번 목업 리뷰 범위에 포함하지 않는다.
