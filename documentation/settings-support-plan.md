# 설정·도움말·작업 접근 복구 목업 구현 계획

작성: 2026-11-04 · 관련 이슈: [#9](https://github.com/capstoneBU-02/capstoneBu-2026-FE/issues/9) · 작업 브랜치: `feature/9-settings-support-mock`

[구현 계획](implementation-plan.md)의 2C를 하나의 PR로 구현한다. [PR #8](https://github.com/capstoneBU-02/capstoneBu-2026-FE/pull/8)의 코드 진입·최초 안내·동의 흐름 위에 설정, 도움말, 작업 접근 실패의 복구 경로를 연결한다. 실제 API는 미확정이며 기존 메모리 목업을 유지한다. 아래 체크 항목은 완료 선언이 아닌 구현·검증 기준이다.

사용자 최신 지시에 따라 **이슈 → 브랜치 → PR** 순서로 진행하고, 독립 리뷰·검사 결과를 PR에서 사용자에게 보고한다. **사용자 리뷰 전에는 병합하지 않는다.** 이 지시는 이전의 자동 병합 허용보다 우선한다.

## 구현 범위

1. **설정**: 현재 워크스페이스와 AI 학습 활용의 미선택·동의·거부 상태를 보여 주고 기존 동의 변경 흐름으로 연결한다. 목록과 설정이 같은 저장소·훅의 상태를 사용한다. 계정 프로필·회원탈퇴 기능을 새로 만들지 않는다.
2. **삭제 요청 안내**: 설정에서 삭제 대상과 처리 단계에 관한 안내를 읽고 닫을 수 있다. 요청을 전송하거나 접수하지 않으며 자료·코드·동의·세션을 변경하지 않는다. 요청·접수·접근 차단·실제 파기를 같은 완료 상태로 표현하지 않는다.
3. **도움말**: 사이드바에서 도움말 메뉴를 열고 FAQ, 이용 안내 다시 보기, 문의하기 안내로 이동한다. 문의 채널은 준비 중이라고 안내하고 가짜 메일 주소·접수 성공·문의 상태를 만들지 않는다.
4. **이용 안내 다시 보기**: 기존 최초 안내 내용을 읽는 경로를 제공한다. 재열람은 온보딩 완료 여부나 동의를 변경하지 않는다. 읽기 경로에서 최초 진입의 확인·저장 동작을 의도치 않게 재실행하지 않는다.
5. **작업 접근 실패 복구**: 없는·삭제된·만료된·접근할 수 없는 작업은 안전한 안내와 내 작업 복귀·필요한 코드 재입력 경로를 제공한다. 다른 워크스페이스의 파일명·구간명·결과를 노출하지 않는다. 정상 작업 상세를 구현하거나 기존 작업을 잘못된 실패 경로에 연결하지 않는다.
6. **경로와 세션**: 내 작업·설정·복구 화면 전환과 브라우저 뒤로/앞으로 가기를 현재 세션 안에서 다룬다. 진입 전이거나 세션이 종료되면 이전 history 항목만으로 자료 화면을 복구하지 않는다. 다른 코드로 재진입한 뒤 이전 워크스페이스의 화면 상태·응답을 재사용하지 않는다.

파일 업로드·처리·정상 작업 상세·오디오·악보·녹음·비교, 실제 인증·권한 검증, 삭제 API, 문의 전송·첨부·답변, 운영자 기능, 배포/CD는 이번 범위 밖이다. 미구현 기능을 이미 이용할 수 있는 것처럼 설명하거나 활성 동작으로 제공하지 않는다.

공동 파일의 실제 수정 소유권은 root가 조정한다. 이 표는 실제 팀원의 기능 담당을 변경하지 않는다. 이번 단계에 오디오·악보 엔진이나 새로운 원격 의존성을 도입할 필요가 없다. 화면 전환만으로 repository를 재생성하거나 선택 동의를 다시 조회·초기화하지 않으며, 메뉴·읽기 전용 안내 상태는 필요한 UI 경계에 둔다.

경로의 내부 화면 값은 `home`·`settings`·`task-not-found`·`task-inaccessible`의 허용 목록으로 제한한다. `navigation.ts`는 파싱·URL·세션 범위 검증, `useWorkspaceNavigation.ts`는 현재 화면과 `popstate`·`pushState`를 담당한다. `history.state`에는 실제 코드·자료 대신 무작위 세션 범위 표식을 사용하며, 화면 쿼리와 허용된 데모 fixture만 URL에서 사용한다. 기존 `WorkspaceSession`·`useWorkspace`를 유지한 채 본문을 전환해 필터·사이드바 접힘·저장소를 보존한다. 재입력으로 진입 상태가 바뀔 때 현재 URL/history와 화면 수명을 정리한다. 이 이름과 구조는 FE 내부 계약이며 서버 라우트나 인증 방식을 확정하지 않는다.

## 검증 시나리오와 완료 기준

- [x] 내 작업 → 설정 → 내 작업 전환에서 현재 워크스페이스·자료·선택 동의가 보존된다.
